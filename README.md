# 🏎️ Web Carros

O **Web Carros** é uma plataforma completa de anúncios de veículos desenvolvida para facilitar a compra e venda de automóveis. O projeto foi construído com o objetivo de consolidar conhecimentos em operações CRUD, autenticação em tempo real e gerenciamento de rotas protegidas.

## 🔗 Demonstração
[Link do Projeto](https://seu-link-aqui.com)

---

## 💻 Sobre o Projeto

O Web Carros permite que visitantes visualizem anúncios, utilizem filtros inteligentes de busca e acessem detalhes específicos de cada veículo, incluindo contato direto via WhatsApp. 

Para anunciantes, o sistema oferece um fluxo completo de login e cadastro, permitindo que gerenciem seus próprios anúncios através de um Dashboard intuitivo e seguro.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi desenvolvido utilizando as melhores práticas e ferramentas modernas do ecossistema Web:

* **[React.js](https://reactjs.org/)** - Biblioteca principal.
* **[TypeScript](https://www.typescriptlang.org/)** - Tipagem estática para maior segurança do código.
* **[Tailwind CSS](https://tailwindcss.com/)** - Estilização moderna e responsiva.
* **[Firebase](https://firebase.google.com/)** - Autenticação e Banco de Dados (Firestore).
* **[React Router Dom](https://reactrouter.com/)** - Navegação e proteção de rotas.
* **[Context API](https://reactjs.org/docs/context.html)** - Gerenciamento de estado global e otimização de requisições.

---

## 🚀 Funcionalidades Principais

-   ✅ **Autenticação Completa:** Fluxo de Login e Cadastro de novos usuários.
-   🔒 **Proteção de Rotas:** Apenas usuários autenticados acessam o Dashboard e a página de novos cadastros.
-   🔍 **Filtro de Busca:** Busca em tempo real por modelos de veículos na página inicial.
-   📱 **Integração com WhatsApp:** Botão de contato direto com o anunciante.
-   📤 **Sistema de Upload:** Estrutura de código pronta para integração com Firebase Storage.
-   🖼️ **Dashboard:** Painel exclusivo para o usuário gerenciar seus próprios anúncios.

## ⚙️ Como executar o projeto

Para rodar o projeto localmente, siga os passos abaixo:

1. **Clone o repositório:**
   ```bash
   git clone [https://github.com/seu-usuario/web-carros.git](https://github.com/seu-usuario/web-carros.git)

2. **Instale as dependências:**
```bash```
npm install

3. **Configure o Firebase:**

 .Crie um projeto no Firebase Console.

 .Ative a Autenticação (Email/Senha) e o Firestore Database.

 .Crie um arquivo .env na raiz do projeto e adicione suas credenciais.

4. **Inicie o servidor de desenvolvimento:**
```bash```
npm run dev

Acesse http://localhost:5173 no seu navegador.
